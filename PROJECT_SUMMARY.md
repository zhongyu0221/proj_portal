# Project Management Portal

## Project Description

Developed a comprehensive **Project Management Portal** using Django, featuring real-time project tracking, task management, user collaboration, and interactive analytics dashboards. This full-stack web application enables teams to efficiently manage projects, track progress, assign tasks, and visualize project metrics through an intuitive interface.

**Key Features:**
- Project creation and management with categories, deadlines, and budgets
- Task assignment and progress tracking with priority levels
- Role-based user management and permissions
- Interactive dashboard with real-time analytics and charts
- Issue tracking and bug management system
- Responsive design for mobile and desktop access
