# Project Management Portal - Django Full-Stack Application

## 🎯 Project Overview

Developed a comprehensive **Project Management Portal** using Django, featuring real-time project tracking, task management, user collaboration, and interactive analytics dashboards. This full-stack web application demonstrates expertise in Django development, database optimization, and modern web technologies.

## 🚀 Key Features

- **Project Management**: Create, track, and manage projects with categories, deadlines, and budgets
- **Task Management**: Comprehensive task system with priorities, status tracking, and team assignments
- **User Management**: Role-based access control with user profiles and permissions
- **Interactive Dashboard**: Real-time analytics with ECharts visualization
- **Issue Tracking**: Bug management with status history and resolution tracking
- **Responsive Design**: Mobile-friendly interface using Bootstrap 5

## 🛠️ Technical Stack

**Backend**: Django 4.1.7, Python 3.11, MySQL  
**Frontend**: Bootstrap 5, JavaScript ES6+, ECharts  
**Testing**: pytest, Factory Boy, 90%+ code coverage  
**Tools**: Git, Django Debug Toolbar, Coverage.py
